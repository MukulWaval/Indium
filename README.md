# Indium 🧪💻

Welcome to **Indium**! This repository contains the Indium compiler and all the necessary tools to get you started with this exciting new language. Let's dive in!

## Getting Started 🚀

To start using Indium, follow these simple steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MukulWaval/Indium.git
   ```
2. **Navigate to the project directory**:

```bash
cd indium
```

3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Run the tests**:
   ```bash
   npm test
   ```
